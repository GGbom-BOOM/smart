# 参考图库

每个人放 3~8 张不同角度/光照/距离的照片。**人名就是身份标签**，两种方式可以混用：

## 方式 A：一个子目录一个人（推荐）

    gallery/
    ├── 张三/
    │   ├── 正面.jpg
    │   └── 侧面.jpg
    └── 李四/
        └── 1.jpg

## 方式 B：平铺，文件名用 `_` 带人名前缀

    gallery/
    ├── 张三_正面.jpg
    ├── 张三_侧面.jpg
    └── 李四_1.jpg

一个人只有一张图时，可以直接叫 `gallery/张三.jpg`。

## 生成特征库

    cd ..
    python3 scripts/build_gallery.py --src gallery --out gallery/gallery.npz --threads 2

生成的 `gallery.npz` 是二进制特征库（不是图片）。加人删人后重跑上面的命令，
再调 ROS 服务 `/reid_reload` 就能热加载，**不用重启节点**。

## 注意

建库输出里会自检每个人内部的相似度，出现这种警告：

    张三               均值 0.365  最低 0.365  <-- 偏低, 建议换更好的参考图

通常意味着**你把不同的人标成了同一个名字**，或者参考图质量太差。先解决它再往下走。
